# Emoji Files Privacy Policy

This repository hosts the privacy policy for **Emoji Files**, published by **MggM Apps**.

The policy page will be available at:

`https://mggmapps.github.io/emoji-files/`

## Support

For questions about Emoji Files or this privacy policy, contact:

**mggmapps@gmail.com**

## Publish with GitHub Pages

1. Add the privacy policy webpage as `index.html` in the repository root.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Replace the URL above with the published GitHub Pages address.

Keep the published privacy policy accurate whenever the app’s features or data practices change.
